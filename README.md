# Computer Vision: X-Ray Classification

## Project Overview
This project explores image processing and deep learning techniques for classifying chest X-ray images into four categories: COVID, Lung Opacity, Normal, and Viral Pneumonia.

## Objectives
- Understand and preprocess medical X-ray images.
- Build an image classification workflow.
- Train and evaluate a model to distinguish between the four image categories.
- Visualize model performance using evaluation graphs.

## Dataset
**COVID-19 Radiography Dataset**

The dataset contains chest X-ray images organized into four classes:
- COVID
- Lung Opacity
- Normal
- Viral Pneumonia

## Technologies Used
- Python
- Google Colab
- Image processing libraries
- Deep learning and machine learning libraries used in the notebook

## Implementation
1. Load and inspect the dataset.
2. Preprocess the X-ray images.
3. Prepare the image classes and labels.
4. Train the classification model.
5. Evaluate the model and visualize the results.

## Project Notebook
Open `IPCV_CAT2.ipynb` to explore the implementation, code, and experimental results.

This is an academic project for educational purposes. The model is not intended for clinical diagnosis or medical decision-making.
